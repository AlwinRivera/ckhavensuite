Bookings overview

Airbnb Booking.com Direct

How it works

  1. Every hour a free GitHub Action pulls the Airbnb and Booking.com calendars (iCal links in data/site.json).
  2. Direct bookings are added to data/direct-bookings.json. You can edit it in the GitHub app or website from your phone.
  3. The Action publishes each unit's direct bookings as a calendar link (below). Paste it into Airbnb's and Booking.com's “Import calendar” so they block those dates too.
